# build-it/

Bonus track. Everything in `.claude/` is finished and pre-wired; this is
where you build one of those finished pieces yourself instead of just
running it.

1. Copy a stub over its finished counterpart, e.g. `cp build-it/verifier.stub.md .claude/agents/verifier.md`.
2. Complete the TODOs.
3. Run the step again (rung 1's verifier, or `/dep-audit`).
4. Compare against `solutions/.claude/` — same file, finished.
